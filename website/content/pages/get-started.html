Get started

Set aside about 15 minutes with Docker and a terminal open. You’ll run one setup command; it starts mAIcro on your own computer and keeps your data there.

A little preparation.

You’ll need an internet connection and a terminal.

  1. Install and start Docker.

    • On macOS (Intel or Apple Silicon) or Windows, start Docker Desktop. (On Windows, you can use PowerShell, or WSL 2 with Docker integration enabled.)
    • On Linux, start Docker Engine or Docker Desktop.
    • If Docker isn’t ready yet, the setup script checks whether it is available, installs or starts it when needed, and asks for permission if configuration is required.

  2. Review the install script first.

    • Before running any piped installer, inspect maicro-install/run.sh (or run.ps1 for Windows) in the bloxez/maicroverse GitHub repository.
    • Note what it does: it can start Docker, request administrator privileges, create configuration and data directories (~/maicro-data by default), modify Linux Docker-group membership, and replace any existing container named maicro (on Windows, it also replaces the platform config file—back up existing data before reinstalling).

Choose your platform.

The command downloads and runs a setup script from the maicroverse repository. The script may ask for your password or administrator approval, create configuration and data directories, and replace an existing mAIcro container. It uses port 4321 by default and keeps your data on your computer.

Back up existing mAIcro data before reinstalling. Follow IDE onboarding and change the default credentials before exposing the service to others.

Select your platform, then copy and run its command.

Windows

Run this command in PowerShell.

irm "https://raw.githubusercontent.com/bloxez/maicroverse/main/maicro-install/run.ps1?cb=$(Get-Random)" -Headers @{ "Cache-Control" = "no-cache" } | iex

Inspect the installation script ↗, then paste the command into PowerShell and follow its prompts.

WSL 2

Run this command inside your WSL terminal.

curl -fsSL https://raw.githubusercontent.com/bloxez/maicroverse/main/maicro-install/run.sh | sh

Inspect the installation script ↗, then paste the command into WSL terminal and follow its prompts.

macOS

Run this command in Terminal. The image supports Intel and Apple Silicon Macs.

curl -fsSL https://raw.githubusercontent.com/bloxez/maicroverse/main/maicro-install/run.sh | sh

Inspect the installation script ↗, then paste the command into Terminal and follow its prompts.

Linux

Run this command in your terminal.

curl -fsSL https://raw.githubusercontent.com/bloxez/maicroverse/main/maicro-install/run.sh | sh

Inspect the installation script ↗, then paste the command into Terminal and follow its prompts.

What happens next?

  1. The script checks Docker and installs, starts or configures it if needed.
  2. It pulls the latest mAIcro image, replaces an existing maicro container if present, and starts your workspace.
  3. It offers to set up mAIcroverse and import all available courses. This optional step requests an OpenRouter API key; you can also set it up later from the course catalogue.

Open your local IDE and help guide.

Once the maicro container is running, open your local workspace using the default links below. Use your configured port if you changed it.

  • Local help: localhost:4321/help/ide/ — start here to get to know the IDE and complete your setup.
  • Local IDE: localhost:4321/instance/maicro/ide
  • GraphQL endpoint: localhost:4321/graphql
  • Setup video — more configuration steps, walked through.

By default, the installer keeps data under ~/maicro-data on macOS, Linux and WSL, or %USERPROFILE%\maicro-data on Windows. The installer guide covers custom locations, updates, and removal.

Set up the mAIcroverse learning instance.

To try the guided courses in an isolated, resettable sandbox, run this while your maicro container is up (review create-mv.sh first if you’d like to see every step):

docker exec -it maicro bash -lc 'curl -fsSL https://raw.githubusercontent.com/bloxez/maicroverse/main/create-mv.sh | bash'

During setup you can enter an OpenRouter API key for AI-powered lessons. Remember that this learning instance uses a known default admin key (maicrog2a) and course scripts wipe their demo data on reset—treat it purely as your practice space, then browse the courses to pick your first lesson.

If something goes wrong.

  • If the local page doesn’t open, wait a moment and retry. Check that Docker is running and inspect docker logs maicro.
  • For setup and help, see the local IDE help page, the setup walkthrough, or Discord.
  • Before you install, read Limits, plainly: alpha software, local-only, development-grade default credentials.
