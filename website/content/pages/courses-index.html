Prepare your learning instance

First, install mAIcro. The installer can create a separate mAIcroverse learning instance and import the courses. This setup asks for an OpenRouter API key; model use may incur charges.

If you skipped that step, run this command in a terminal while mAIcro is running. It downloads and runs the learning setup script inside the container:

docker exec -it maicro bash -lc 'curl -fsSL https://raw.githubusercontent.com/bloxez/maicroverse/main/create-mv.sh | bash'

Before running or repeating it: the script creates or updates the maicroverse instance, resets its admin key to maicrog2a, imports course scripts, overwrites matching sample files, allows outbound fetches to any host, and configures OpenRouter models and credentials. Review the script and back up anything you want to keep. Change the default admin key after connecting, before exposing the instance to others.

In the IDE, connect to the maicroverse instance and open scripts/courses in the project tree. Use a disposable learning instance: some course setups delete or replace data. Read each course’s warning and README before running its scripts.

To open a course straight from this site, save the learning instance’s IDE address below, for example http://localhost:4321/instance/maicroverse/ide. The button needs an IDE version that supports website course links; on older versions, open the README from the project tree instead. Browsers may block checks from an HTTPS website to an HTTP network address.
