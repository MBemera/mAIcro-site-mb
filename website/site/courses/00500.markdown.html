Markdown Foundations

Write, preview and connect documents in mAIcro.

Course objective

Learn Markdown by building readable pages and a small connected wiki.

What you’ll learn

  • Format text, headings, lists and tables.
  • Link pages and include media from File Storage.
  • Use code, diagrams and the Markdown browser to build a useful wiki.

Before you begin

The media lessons use the mAIcroverse wiki sample files.

Open the course in your IDE.

Open the course README in your mAIcro IDE. You’ll need an instance with the courses installed; see Prepare your learning instance in the course catalogue. Opening the README won’t run any scripts.

On an older IDE without website course-link support, open scripts/courses/00500.markdown/00.readme.md from the project tree instead.

Connect your IDE below to enable this button.

Connect your IDE

Running mAIcro? Save your IDE address to open courses right in your IDE. The address is saved only on this device, and you sign in within the IDE — the website never sees your credentials.
