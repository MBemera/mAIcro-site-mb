Learning by making

A little curiosity can be the beginning of something useful.

What happens when you take an idea, break it into small steps, and try it? You get more than a finished tool: you begin to understand how the pieces fit together.

Start with a question

Pick a question small enough to explore in an afternoon. For example: how could I keep a collection of useful notes and find the right one later? Write down what you’d like to put in, and what a helpful result would look like.

You don’t need to understand every technical term before you begin. Give yourself permission to experiment, change direction, and ask why something happened.

For a notes experiment, begin with three fictional notes and a question you can answer from one of them. Try finding the right note, then change the question. Notice what helped you find it and what made the task harder. Those observations are part of the learning, not a detour.

Learn with AI, not just about it

An AI assistant can help you break a task into steps, explain an unfamiliar concept, or suggest something to try. An agent can use tools to help carry out work. In either case, you’re still the person deciding what matters and checking the outcome.

Ask for an explanation in your own words. Try the suggested step, look at the result, and compare it with what you expected. If it doesn’t make sense, ask another question. AI can make mistakes, so treat its answers as things to investigate rather than automatic truth.

Try a course

Explore the courses for practical ways to learn by doing. Install mAIcro, set up the optional learning instance, and choose a starting point that interests you. The course catalogue explains how to prepare that instance and what the setup changes.

Markdown Foundations is a place to practise writing and linking documents. If you’re curious about connecting services, API Wrappers introduces a public example before optional API-key exercises. Read each course’s preparation and warnings, then open its README in the IDE for the lesson steps. Some exercises change or delete data, so use a disposable learning instance.

Start with practice information, especially when using an external AI service. Check what data a tool sends and where it goes. You can learn plenty without handing over personal documents.

After an exercise, write down one thing you expected, one thing that happened, and one question you still have. Try a small variation and see whether the result changes. The aim isn’t to know everything at once; it’s to understand a little more each time you make something.
